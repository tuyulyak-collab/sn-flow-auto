Chain (Image → Video)

For every prompt, generate the image first, then auto-feed it to a video gen.

Use {prompt} to insert the image prompt. Leave empty to use the image prompt verbatim.

Each prompt becomes 2 queue rows: image step + chained video step. The video step waits for the image to complete, then attaches the image as input for the video gen.
