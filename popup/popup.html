Chain (Image → Video)

For every prompt, generate the image first, then auto-feed it to a video gen.

Use {prompt} to insert the image prompt. Leave empty to use the image prompt verbatim.

Each prompt becomes 2 queue rows: image step + chained video step. The video step waits for the image to complete, then attaches the image as input for the video gen.

Download Settings

Choose how SN Flow Auto names and organizes downloaded files.

Choose the default name pattern for downloaded files.

Available shortcuts:

  • {random5} = random 5 letters/numbers
  • {ddmmyyyy} = today’s date
  • {mode} = image, video, or chain
  • {index} = queue number
  • {promptSlug} = short prompt text

Files will be saved inside your Chrome Downloads folder.

Examples:

  • SN Flow Auto
  • SN Flow Auto/Images
  • SN Flow Auto/Videos
  • SN Flow Auto/{ddmmyyyy}

For Chrome security reasons, extensions can only save automatically inside Downloads or subfolders inside Downloads.

Recommended. This prevents old files from being overwritten.
